# Xiyao Wang - Personal Homepage

Source for [ali-xiyao.github.io](https://ali-xiyao.github.io/), a lightweight static academic homepage.

## Local preview

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

Then open <http://127.0.0.1:8080>.
